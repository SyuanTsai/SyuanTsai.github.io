# Personal notes site

A Jekyll site containing technical notes, articles, and the build and
validation tooling used to publish them.

## Rights boundary

This repository separates site implementation from editorial content:

- implementation and build paths have a proposed MIT scope;
- original articles and media have a proposed CC BY 4.0 scope;
- external themes, gems, images, quotations, and linked material retain their
  original rights.
