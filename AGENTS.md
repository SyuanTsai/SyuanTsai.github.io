# Repository instructions

Before modifying any tracked file, read and follow:

- `docs/public-content-and-pr-policy.md`
- `docs/article-authoring.md` for article changes
- `docs/site-delivery.md` for publishing or build changes

Mandatory rules:

- Treat every tracked file, branch, commit, draft, unlisted preview, and pull request as public.
- Never write real personal or work identifiers, internal names, credentials, local usernames, or local paths. Use the placeholders defined in the public-content policy.
- Work only on a non-default branch and open a Draft Pull Request.
- Never mark a PR ready, merge, publish, force-push, rewrite the default branch, or delete branches without explicit owner approval in the current conversation.
- Before each commit, inspect the exact diff for sensitive information.
- If sensitive information is committed, stop. Report the exact exposure and wait for cleanup direction; a later replacement does not remove earlier commits or PR diffs.
